# Smart Mess — Queue Forecasting System

**Granica × IIT Guwahati Hackathon submission**

Predicts the main-dish line length **5, 10 and 15 minutes ahead** in an IIT Guwahati hostel mess, giving the mess manager an actionable alert 10–15 minutes early and telling students whether to go now or wait.

---

## Quick Start

```bash
pip install -r requirements.txt
python run_all.py          # ingest → export → EDA → train → ablation → predict → wait-validation
streamlit run dashboard/app.py
```

The dashboard replays every held-out session with live-style forecasts.

---

## Validation — Forward Out-of-Sample Split

We use a **single, strictly chronological split** with no data leakage:

| | Days | Sessions |
|---|---|---|
| **Train** | First 12 of 17 dates (7–22 Sept) | 36 sessions (synthetic weekdays) |
| **Test (held out)** | Last 5 dates (23–27 Sept) | 15 sessions (9 synthetic + 6 real weekend) |

- The model is trained on all sessions before the cutoff date and evaluated on everything after.
- Real weekend sessions (Saturday 26 Sept & Sunday 27 Sept) land in the **test set** — the model never saw them during training.
- Every forecast shown in the dashboard and demo was made by this same test-set model.

## Data

| Folder | Contents |
|---|---|
| `data/real/` | 6 real weekend meals (MESSA, 26–27 Sept 2026), `is_synthetic = 0` |
| `data/synthetic/` | 45 synthetic weekday meals (7–25 Sept, Mon–Fri), `is_synthetic = 1` |
| `data/processed/` | Merged 5-min interval parquet (auto-generated by `run_all.py`) |
| `data/parquet/` | Open-access parquet export with embedded schema |

Synthetic sessions were generated from direct observations (meal patterns, service rates, arrival distributions) and clearly labelled. Real sessions were collected with a tap-logger app (no cameras, no names, manager approval obtained).

---

## Pipeline

```
src/ingest.py          → reads data/real/ + data/synthetic/ taps (IN, OUT, SERVED), bins & derives queue
src/export_parquet.py  → writes data/parquet/ with embedded schema metadata
src/eda.py             → reports/eda_report.md + reports/figures/eda_*.png
src/train.py           → forward split evaluation, model selection, saves models/queue_forecaster.joblib
src/ablation.py        → feature ablation on forward split → reports/ablation_queue_profile.md
src/predict.py         → out-of-sample predictions → reports/predictions_dashboard.parquet
dashboard/app.py       → Streamlit dashboard (replay + live forecast)
```
